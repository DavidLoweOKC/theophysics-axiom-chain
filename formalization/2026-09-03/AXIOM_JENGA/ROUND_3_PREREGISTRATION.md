# Axiom Jenga — Round 3 Preregistration

## Competing architectures

1. Love and Truth are independent co-primitives.
2. Love is primitive and Love -> Truth is supplied as a bridge.
3. Truth is primitive and Truth -> Love is supplied as a bridge.
4. A common ground is primitive and independently supplies both Love and Truth.

All four retain the same downstream rules and shared inputs.

## Questions

- Can each architecture reach the same seven spiritual targets?
- Does bare propositional logic select either Love -> Truth or Truth -> Love?
- Does the common-ground model truly reduce assumptions, or trade visible roots
  for two bridge commitments?

## Kill conditions

- If all four architectures reach the same closure, closure success cannot be
  used to establish priority among them.
- A smaller visible primitive count is not a smaller assumption count when it
  requires additional bridge propositions.
- A common ground must not be silently identified with God, Axiom 0, Logos, or
  any physical object.  Those are separate identification bridges.
