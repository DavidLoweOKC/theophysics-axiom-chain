# Divine Order Generator Test

## Candidate rules under test

1. Adequate Love entails personhood/distinction.
2. Love + Truth + moral order + a real violation enable Justice.
3. Justice + Love + agency enable a Mercy candidate.
4. Mercy + an external source + agency enable a Grace candidate.
5. Grace + binding dynamics enable a Peace candidate.
6. Peace + positive reduced mass enable a Joy candidate.

These are semantic assumptions supplied to the model. The generator search does
not prove their theological or physical truth.

## Candidate primitive universe

- Love
- Truth
- Agency
- Moral order
- Real violation
- External restorative source
- Binding dynamics
- Positive reduced mass

The test exhaustively checks all 256 subsets. Lean separately verifies closure,
the failure caused by removing each primitive, and uniqueness of the minimum
within this declared universe.

## Interpretation boundary

If the test passes, it means this rule system has a compact, nonredundant basis.
It does not mean the basis is unique across every possible formalization. New
rules or new primitives can change the result, so the rule registry and its
semantic provenance are part of the receipt.
