# Formalization package — 2026-09-03

This is a preserved import of the September 3 formalization and validation work.
It contains Lean source modules, gauntlet compilation receipts, audit notes, and
Z3 validation scripts/receipts. It is intentionally separate from the canonical
axiom-chain source so that package-specific formal results do not silently alter
canon status or theological interpretation.

## Scope

- Lean files formalize declared definitions, hypotheses, and consequences.
- Z3 materials record satisfiability and countermodel checks for their stated encodings.
- Audit and receipt files preserve the testing history and stated limits.

Successful formal checks establish results only within their encoded premises;
they do not by themselves establish physical instantiation, theological identity,
or final canon admission.

Local `.fisnote` metadata is deliberately excluded from this publication surface.
